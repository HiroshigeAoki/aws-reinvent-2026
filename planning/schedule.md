# 日別計画

すべて現地時間 `America/Los_Angeles`。具体的な参加枠はまだ確定していません。

| 日付 | 計画メモ |
|---|---|
| 2026-11-29（日） | 公式Agendaで受付・事前アクティビティを確認 |
| 2026-11-30（月） | 初日。候補セッションの会場と移動を確認 |
| 2026-12-01（火） | 演習・質問の時間を確保 |
| 2026-12-02（水） | 代替開催回を含めて候補を調整 |
| 2026-12-03（木） | 未解決の質問と追加演習を整理 |
| 2026-12-04（金） | 学びと帰宅後の実験計画をまとめる |

予定の機械チェックには [schedule.json](schedule.json) を使います。候補の開始・終了が公式で確認できたら、data/catalog.json にオフセット付き時刻を入力し、参加予定を `planned` にします。公式予約を確認した場合のみ `reserved` に変更します。

```bash
python3 scripts/reinvent.py check-schedule
```

異なる会場への移動余裕は仮に45分。これは公式の移動時間ではなく、調整可能な計画上の目安です。会場情報や時刻が不足している場合は、チェックできない項目が残ります。

2026年公式AgendaのPDT表記には開催時期のタイムゾーンとの不一致が見られます。このrepoはIANAタイムゾーンを使います。11月末〜12月初旬のLas VegasはUTC−08:00で、日付をまたぐ日本時間との混同を避けます。予約時には公式ポータル・アプリの表示を再確認してください。
