# 参加候補と優先順位

catalog は候補の蓄積。shortlist はそこから優先度と理由を付けた絞り込み。schedule は時間まで確定した予約案、という役割分担です。初期案なので、内容・時間の確認後に更新します。

| 優先 | テーマ | 現地で得たいもの |
|---|---|---|
| A | AIを使う開発・レビュー | 速度と品質を両立する具体的な開発習慣 |
| A | Workshop / GameDay | 手を動かす経験、講師や参加者との対話 |
| A | AIエージェントの実装・運用 | 評価、権限、観測、障害時の設計判断 |
| B | サーバーレス・API | 実装の複雑さ、性能、費用の比較材料 |
| B | アーキテクチャ・コスト | 今後の設計に使える判断基準 |

セッション一覧は [docs/catalog.md](../docs/catalog.md)。同一内容の繰り返し回は代替候補として比較します。

## 選ぶときの問い

- 今の知識から何が増えるか。
- 公式動画の視聴に加えて、現地で質問・演習する価値があるか。
- 直前の予定から移動・入場に間に合うか。
- 参加後に試す小さな実験を一つ想像できるか。
