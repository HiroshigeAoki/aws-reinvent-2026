# Working rules

- This is an unofficial personal learning and event-planning repository. Keep documentation in Japanese and code comments concise.
- Read README.md and docs/content-policy.md before edits. Use only public information in committed notes. Keep personal logistics under ignored `private/`.
- Consult the official catalog before adding or changing a session. Preserve session ID, year, source URL, and `checked_on`. Never infer a reservation, duration, venue, speaker, or availability.
- In `data/catalog.json`, each session **must** have `title` (official English title, verified on the catalog). `title_ja` is an **optional** short helper label, not a formal translation.
- Do not commit official abstract full text, transcripts, or machine-generated summary bodies. Products of fetch/summarize stay under `local-data/` (gitignored); never stage them.
- `data/catalog.json` is the selected catalog input. `docs/catalog.md` and `sessions/*/*/README.md` are generated by `scripts/reinvent.py render`. Edit the input, then regenerate.
- `notes/` and `planning/*.md` are authored content. Do not overwrite them when refreshing the catalog. For notes polishing with Qwen, see docs/qwen-notes.md.
- Use America/Los_Angeles for event times. Retain explicit UTC offsets. Unknown timestamps stay null. Do not copy 2025 schedule details into 2026.
- Keep Japanese selection reasons (`why_ja`) short. Link to official pages rather than copying abstracts, transcripts, slides, videos, or logos.
- Do not introduce automated crawling or authenticated content retrieval without confirming permission and scope.
- Validate with `python3 scripts/reinvent.py validate` and `python3 -m unittest discover -s tests -v`. After render, inspect the diff. No dependency installation is required.
- Do not mark an item reserved unless the user confirms the official reservation. Repository status does not book a seat.
